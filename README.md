## Running Solutions

Each topic has its own `Program.cs` runner. To run all solutions, execute the project from the root:

```bash
dotnet run --project Algorithms/Algorithms.csproj
```

The root `Program.cs` calls each topic runner in sequence:

```csharp
ArrayEasyRunner.Run();
StringEasyRunner.Run();
MathEasyRunner.Run();
// ...
```

To test only a specific topic, call the runner directly from the corresponding `Program.cs`.

---

## Naming Convention

- **File names** match the LeetCode problem title exactly (e.g. `ContainsDuplicate.cs`)
- **Namespaces** follow the folder path: `Algorithms.{Topic}.{Difficulty}.Solutions`
- **Each solution** exposes a `public static Run()` method

```csharp
namespace Algorithms.Array.Easy.Solutions;

public static class TwoSum
{
    public static int[] Run(int[] nums, int target)
    {
        // solution
    }
}
```
